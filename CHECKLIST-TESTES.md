# Checklist de validação — Aula 11

## Inicialização

- [ ] Abrir o Dashboard e conferir os totais.
- [ ] Abrir Alunos, Cursos, Matrículas e Usuários.
- [ ] Conferir as quatro chaves no LocalStorage.

## Alunos

- [ ] Cadastrar um aluno.
- [ ] Atualizar a página e confirmar a permanência do registro.
- [ ] Editar os dados de um aluno.
- [ ] Alterar o status de um aluno.
- [ ] Atualizar a página e confirmar a alteração.
- [ ] Buscar por nome, CPF ou e-mail.
- [ ] Filtrar por status.
- [ ] Confirmar que busca e filtro não alteram o LocalStorage.
- [ ] Remover um aluno.
- [ ] Atualizar a página e confirmar que ele não reaparece.
- [ ] Restaurar os dados iniciais dos alunos.

## Cursos, matrículas e usuários

- [ ] Cadastrar, editar e remover um curso.
- [ ] Cadastrar, editar e remover uma matrícula.
- [ ] Cadastrar, editar e remover um usuário.
- [ ] Atualizar a página e conferir a persistência.
- [ ] Conferir que os usuários não possuem campos de senha.

## Tratamento de erros e restauração

- [ ] Definir uma chave de alunos com JSON inválido pelo console.
- [ ] Atualizar a página e conferir o tratamento sem interrupção.
- [ ] Restaurar os dados iniciais dos alunos.
- [ ] Testar `removeItem()` em uma chave de teste.
- [ ] Testar `sessionStorage`.
- [ ] Testar `localStorage.clear()` somente depois de conferir as chaves.
- [ ] Voltar ao Dashboard e restaurar todos os dados iniciais.

## Identificadores

- [ ] Cadastrar um aluno.
- [ ] Remover um registro intermediário.
- [ ] Cadastrar outro aluno.
- [ ] Conferir que o novo identificador não se repete.
